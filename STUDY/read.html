Load a transcript from your machine

Timestamped transcripts (tactiq, SRT-style 00:00:00.000 text) or plain lines. It is parsed and resolved in this page — nothing is uploaded, and nothing is added to the repository. If the file names a YouTube URL in a header comment, the player wires itself up to that video automatically.

Word matching here is exact only: Telugu script against the deck's Telugu script. The offline pipeline does better where it can be used, because it can romanize and filter English — but it can only be used on material that may be committed.

Words you're working on

Everything marked learning. Words already in the deck just need unsuspending; the rest need a definition before they can be imported — that is the list to take to a dictionary, or to your wife.

How the matching works, and where it is guessing

Words are resolved against the word master before the page is built. An exact match is reliable. A match marked like this is approximate: the text and the deck use different romanization conventions — adhi against adi, kooda against kūḍā — and the two are collapsed onto one skeleton to match at all. Usually right, occasionally not, so it is flagged rather than trusted.

Marking a word known writes to the same store the vocabulary queue uses, so it also unlocks sentences in the drill. That only happens for words that exist in the master; anything else has no deck identity yet, which is exactly why it is worth mining.
