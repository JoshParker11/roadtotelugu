Telugu Romanizer, on the phone

Neither phone can run the Chrome extension — Chrome for Android has never supported extensions, and Chrome for iOS has no extension API at all. A bookmark can do it instead.

A bookmarklet is a bookmark whose address is a line of JavaScript rather than a web address. Tapping it doesn’t go anywhere: it runs that line on the page you are already looking at. Here, that line loads the romanizer into Language Reactor.

అది ఏమిటి?
adi ēmiṭi?

1 · Copy one of these

Telugu — project scheme

ā ī ū ē ō · ṭ ḍ ṇ ḷ. Maps back to exactly one spelling. Start here.

javascript:(function(){var d=document,s=d.createElement('script');s.src='https://joshparker11.github.io/roadtotelugu/chrome-extension/mobile/loader.js?scheme=iso&v='+Date.now();d.head.appendChild(s);})()

Telugu — colloquial

What people actually type: nenu, kooda, thinu. Lossy on purpose. Optional second bookmark — tapping it while the first is running switches scheme.

javascript:(function(){var d=document,s=d.createElement('script');s.src='https://joshparker11.github.io/roadtotelugu/chrome-extension/mobile/loader.js?scheme=colloquial&v='+Date.now();d.head.appendChild(s);})()

2 · Make it a bookmark (iPhone, Safari)

Safari won’t let you type a javascript: address directly, so you save an ordinary bookmark first and then edit it. This is the fiddly part, and it is once only.

  1. On any page: Share → Add Bookmark → name it Telugu → Save.
  2. Bookmarks (open-book icon) → Edit → tap Telugu.
  3. Select the whole address line, delete it, and paste what you copied above.
  4. Done.

3 · Use it

  1. Open Language Reactor and open one of your texts.
  2. Bookmarks → tap Telugu.

Romanization appears under every line. It keeps working as you scroll, tap words and move between texts, because Language Reactor never actually reloads the page — so it’s one tap per session, not per text.

Tapping it again turns it off, and again turns it back on. Tapping the other scheme’s bookmark switches scheme in place. Nothing is ever written to your Language Reactor text: the romanization is added to what’s on screen, so your saved text and your Words list stay exactly as they were.

If nothing happens

Make sure the address really starts with javascript: — iOS sometimes helpfully strips it on paste. Re-editing the bookmark and pasting again fixes it. If you get an alert saying it couldn’t load a file, the phone is offline or GitHub Pages hasn’t finished deploying.

Android

Bookmarklets are unreliable across Android browsers — Firefox blocks javascript: from the address bar and Chrome needs an awkward workaround. The tablet is better served by a real Firefox add-on, which is a separate job.
